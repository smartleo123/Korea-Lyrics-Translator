# 本機 AI 語意對齊（實驗性）

此功能由使用者點擊「免費本機 AI 詞組對齊」後才啟動，以 Transformers.js 3.8.1 載入 Hugging Face 公開的 `Xenova/paraphrase-multilingual-MiniLM-L12-v2` 量化模型（約 118 MB，加上其他模型資源）。瀏覽器使用 CPU/WASM 計算；模型可依瀏覽器策略快取。不需要註冊 API Key，但仍須連網下載模型。

韓文使用字面 Hangul 詞組，繁體中文透過 Intl.Segmenter 切詞；兩側產生多語言向量，利用 cosine similarity 與雙向最近鄰得到候選對齊。低相似度或歧義配對會保留未對齊。最多檢查前 12 行有中文譯文的歌詞。**向量相似不代表翻譯或漢字詞源正確**；介面只顯示建議，不會覆蓋原標註，也不輸出到 PDF。這是瀏覽器嵌入式語意比對，不是 SimAlign 原版演算法。

原網站的中文句子仍由 MyMemory 提供（免費服務，但需把文字傳到第三方）；本機模型不代表整個網站都離線。模型下載、裝置記憶體、瀏覽器支援與韓中單詞的跨語言向量品質都可能影響結果。若需比較實際準確率，請使用 benchmark/ 的人工對齊資料與評分器。
