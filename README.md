# Korea Lyrics Translator · 韓語歌詞詞源標註器

[開啟網站](https://smartleo123.github.io/Korea-Lyrics-Translator/)

以繁體中文閱讀韓語歌詞：貼上原始歌詞，自動辨識漢字詞（紅色、附漢字）、固有詞／文法（白色）、外來語（紫色），所有註解一開始就顯示。點選詞彙修正，結果可下載成獨立 HTML。

## 技術實作

- **韓語形態分析**：[Garu](https://github.com/ongjin/garu) (WebAssembly，Apache-2.0)，在瀏覽器上執行，支援語尾與助詞的語法分割。
- **漢字詞典**：[HanjaHanja Dictionary](https://github.com/ongocompany/hanjahanja-dict)，基於國立國語院 우리말샘／標準國語大辭典衍生資料。CI 在部署時生成數萬筆可查詢的詞條；同音同形詞的多個漢字寫法保留為候選，而不擅自選擇。
- **人工校正**：內建小詞庫優先指定部分固有詞等常見誤判；亦可點擊任何詞修正，並將結果保存在瀏覽器 localStorage。可匯入／匯出 JSON 詞庫。
- **純靜態網站**：使用 Vite 建置至 `dist/`，GitHub Actions 自動部署 GitHub Pages，不需伺服器或 AI API Key。

## 辨識限制

**詞源分類並不等於正確翻譯。** 形態分析模型會出現切詞與詞性錯誤，歌詞中省略、口語、縮寫、押韻轉寫等尤其容易混淆。缺詞和多義詞會標示「待確認」或「漢字歧義」，不會把第一筆同音漢字冒充為正解。固有詞的中文釋義目前以精選詞庫為主；沒有詞義的詞不杜撰翻譯。人稱、助詞與語尾沒有必要填漢字。

詞典來自原始辭典整理，不保證每首歌都達到「完整」或「高準確率」；尤其漢字詞的上下文選字需要人工確認。

## 免費韓中機器翻譯補充

站內預設啟用 MyMemory 免費中文翻譯，不需勾選選項。使用者點擊「自動標註歌詞」後，先執行 Garu 分析與詞源查詢，再把沒有中文釋義的**單個韓語詞彙**（而非整首歌）透過 [MyMemory 公開翻譯 API](https://mymemory.translated.net/doc/spec.php) 嘗試翻成繁體中文。

- 不需要 Google API 金鑰；採免費第三方服務，受可用性、每日配額、跨網域限制等因素影響。
- 每次最多查詢 40 個不同詞彙，每次請求間隔約 350 毫秒。相同詞的譯文快取在本地瀏覽器；不會重複翻譯已知註解。
- 繁體中文機器翻譯直接顯示括號內詞義，不另加前綴；**機譯可能失準**，不能證明漢字詞的詞源。
- 目前按「自動標註歌詞」會將需要補詞義的韓文單詞送往 MyMemory，請勿貼入敏感或私密內容。
- 外部服務回覆失敗、沒有翻譯或配額不足時保留原詞，不編造中文字。
- 若要穩定、準確的上下文翻譯，可後續用官方 Google Cloud Translation API（需 Google Cloud 計費設定和安全的伺服器端代理）。**不建議把 Google Cloud API 金鑰直接寫在公開 GitHub Pages 前端**。


## 載入與一次輸出

翻譯期間顯示「歌詞翻譯中」及轉圈動畫，等待本次查詢完成或失敗後才一次顯示結果。未取得譯文的詞保留原韓文、不顯示「待確認」，原詞可以點擊人工修改。此 UI 不代表每個詞都被成功翻譯；受 MyMemory 免費服務額度所限，一次最多向服務查詢 40 個不同詞。

## 以歌名搜尋歌詞

1. 輸入韓文歌名（可另外填歌手），點「依歌名搜尋歌詞」。
2. 網站使用 [LRCLIB 公開 API](https://lrclib.net/docs) 查詢歌曲版本。確認歌手和版本後點「帶入歌詞」，在瀏覽器端取回對應的歌詞。
3. 若找不到、第三方服務不可用，或曲目沒有可讀取的文字歌詞，仍可直接貼上自己有權使用的韓文歌詞。
4. 取回歌詞不代表內容一定正確，也不代表本專案取得第三方歌詞的再發布授權。本站不在儲存庫中存放歌曲歌詞，使用者須遵守相關服務條款與著作權規定。

## 逐行繁體中文歌詞翻譯

點選結果區右上角「顯示逐行中文翻譯」，逐行中文會放在韓文詞源標註的下方。可隨時切換顯示或隱藏，並保留原始韓文歌詞的行序與空白段落。顯示中文時，下載的 HTML 也會包含當前逐行翻譯。

- 「已有官方或授權的中文歌詞？」區塊可以貼上你已取得授權可使用的中文翻譯，系統**優先使用使用者提供的譯文**，缺少的行才使用 MyMemory。
- 頁面提供 Apple Music 官方歌曲搜尋入口，方便查看該歌曲有沒有官方翻譯。Apple Music 的公開開發者 API 不提供可直接複製的官方中文歌詞全文，因此**本站不會謊稱已自動取得官方譯文**。
- 沒有提供官方譯文或缺漏的行，系統會由 MyMemory 產生機器翻譯，**這不是官方中文歌詞**，且可能偏離上下文。
- 逐行譯文按原行序對齊，翻譯中顯示載入動畫，待查詢結束才一次輸出。免費 MyMemory 有額度、速率及可用性限制，遇到失敗的行不會編造內容。
- 從第三方搜尋到的歌詞、機器翻譯和使用者貼上的文字不儲存於伺服器；中文翻譯快取存在瀏覽器本機。查詞與翻譯仍會傳送所需文字至第三方 API。

## 依歌手搜尋相關歌曲

新增「依歌手搜尋歌曲」功能：只填寫歌手名稱即可搜尋，不需要先知道歌名。結果以歌名列出，同一首歌的不同錄音／專輯版本會合併展示，並提供版本選擇和「帶入歌詞」。

- 來源：LRCLIB 的關鍵字查詢 `/api/search?q=歌手`。系統會額外檢查歌手名稱，剔除只是標題碰巧符合關鍵字的歌曲。
- 歌手可能有不同的韓文、英文或羅馬拼音藝名，搜尋不到時可以換另一種名稱嘗試。
- **LRCLIB 每次最多 20 筆曲目且不能分頁**，這是「查找相關歌曲」，不是完整歌手作品全集。搜尋與實際可取得歌詞的結果也受資料庫收錄和服務可用性影響。
- 既有「依歌名搜尋歌詞」、手動貼上歌詞、韓語詞源註解與逐行中文翻譯功能均保留。
