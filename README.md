# Korea Lyrics Translator

韓語歌詞詞源三色對照工具（靜態 GitHub Pages 網站）。

## 使用方式
1. 開啟網站並貼上韓文歌詞，填寫歌曲名稱。
2. 點擊「自動標註歌詞」。
3. 紅色表示漢字詞（附漢字）、白色表示固有詞（附中文義）、紫色表示外來語／英文。
4. 所有註解預設可見；點擊詞彙可人工修正並儲存在瀏覽器自訂詞庫。
5. 可下載完整標註 HTML、複製文字、匯入／匯出 JSON 詞庫。

## 網頁網址
若已在儲存庫的 **Settings → Pages** 設定從 `main` 分支根目錄發布：
https://smartleo123.github.io/Korea-Lyrics-Translator/

## 辨識限制
目前是 **純前端、內建詞典式 MVP**，不是雲端 AI 或完整韓文形態分析。未知詞以「待確認」標示，不自行杜撰漢字；複合詞、助詞、活用詞尾、歧義詞的切分仍可能不完美，可透過點擊逐詞修正並逐漸擴充詞庫。

資料處理在瀏覽器本機完成，不需 API 金鑰，也不會把貼入的歌詞上傳給網站伺服器。自訂詞庫存在瀏覽器 localStorage（也可以匯出 JSON 備份）。

## 開發
直接開啟 `index.html`，不需要安裝相依套件。
